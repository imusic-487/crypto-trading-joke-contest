## The joke

> I bought the dip. Then the dip bought a shovel and kept digging.

## How it works

`main.py` writes that one line to `/output/entry.txt` (64 characters, UTF-8),
where the contest's judge reads it. Run it with:

```sh
python3 main.py
```
